# Поиск кратчайшего пути (лабораторная работа)

Оконное приложение на C++/Qt. Ищет кратчайший путь в транспортной сети
методом динамического программирования. Сеть задаётся как ориентированный
граф: узлы — пункты, рёбра — магистрали с известной стоимостью проезда.

Лабораторная работа по курсу
«Математическое программирование и оптимальное управление».

## Организация кода — ООП

Проект построен на классах. Логика графа, алгоритм и проверки данных
отделены от графического интерфейса.

Протестировано на Qt 6.9.3, MSVC 2022, но должно собираться на любом
Qt 5.15+ или Qt 6 с компилятором C++17.

## Требования

- Qt 6 (модули Core, Gui, Widgets), также поддерживается Qt 5.15+
- Компилятор C++17 (MSVC, MinGW, GCC или Clang)

## Сборка

### Через Qt Creator

Открыть `ShortestPathApp.pro` в Qt Creator.
Выбрать kit (Qt 6, компилятор C++17).
Нажать Configure Project.
Запустить — Ctrl+R или зелёная кнопка слева внизу.

При первом запуске уже загружен демонстрационный граф из 8 узлов —
можно сразу нажать «Найти кратчайший путь» для проверки.

### Из командной строки

```
qmake ShortestPathApp.pro
make         # MinGW/GCC
# или nmake  # MSVC
./ShortestPathApp
```

## Использование

1. Задать число узлов, начальный и конечный узлы.
2. Добавить рёбра вручную или загрузить файл («Загрузить из файла…»).
3. Нажать «Найти кратчайший путь» — на схеме подсветится путь,
   ниже появится подробный расчёт.
4. «Сохранить ход решения в .txt…» — сохранить все шаги в файл.

## Формат входного файла

Первая значимая строка — число узлов. Дальше идут рёбра:
откуда, куда, вес. Строки с `#` и пустые игнорируются.

```
# Пример сети из 8 узлов
8

1 2 5
1 3 3
2 4 6
...
```

Готовый пример лежит в `example.txt`.

## Какие проверки делает программа

- отрицательные веса рёбер;
- петли (рёбра вида v → v);
- повторяющиеся рёбра;
- циклы в графе (метод ДП работает только на графах без циклов);
- можно ли вообще добраться от начального узла до конечного;
- тупиковые узлы — выводится предупреждение.
